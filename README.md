# 新神鵰俠侶

一款直排的文字冒險遊戲，全十六回。改編自金庸《神鵰俠侶》。

非商業的個人設計習作。原著權利屬於原權利人，本專案與原權利人無任何關聯。

**→ [開卷](https://ian3738.github.io/shendiao-narrative/)**

---

## 這是什麼

把《神鵰俠侶》這個故事，好好講一遍。

不是解構它，不是拿它當機制實驗的載體。是讓玩家跟著楊過從嘉興城外的破窯走到華山之巔，把這一路上的人、事、情，一件一件經歷過去。

- **全十六回**，一輪約讀 1,540 行
- **直排文字**，由右至左；對白的說話者自成一列
- **兩個看得見的數值**：情意、俠名
- **簡化但真實的戰鬥**：真氣制，有招式、有輸贏、有後果
- **單一存檔**，自動覆寫，不可回頭
- **無音訊**

滑鼠點擊或空白鍵推進。手機、平板、桌機都可以。

## 兩個數值會互相拉扯

**情意**是他與小龍女之間的羈絆。**俠名**是江湖怎麼看他。

這兩條不是各自累加的分數——它們會對撞。第七回在大勝關，他贏了霍都、拿到全場的發言權，然後當著幾百個人說要娶自己的師父。

那一句話讓情意大漲、俠名重挫。沒有一個選項能讓他全身而退。

這一刀是原著的核心，數值就照實反映。

## 幾個實作上的決定

### 第十三回：十六年要好看

十六年的空白是這個故事最難處理的部分。早期版本把它做成「刻意的無聊」——事後看那是錯的。

現行版做成**六個獨立的單元劇**：〈名〉〈燈〉〈冬〉〈數〉〈鵰〉〈傳〉。每一個都完整，挑選標準是每一則都要看得見他變成傳說的一小步。

它不是六段空白，是一個人怎麼從楊過變成神鵰俠。

### 黯然銷魂掌的機制

早期設計寫成「情意越高越強」。那是錯的。

原著的邏輯更好：那一路掌法是十六年的思念裡練出來的，**她回來之後他反而使不出來**——因為他不再是一個人了。要等到他再一次面臨失去，它才回來。

### 第九回沒有任何介面把戲

早期版本用「選項全部變灰、封鎖三秒」來演斷臂那一刻。現行版拿掉了所有機關，就把它寫好——他不是不能擋，是他這輩子沒有防過那個人，根本沒有想到這件事需要防。

### 直排的對白

說話者的名字自成一列，排在對白右側，中間一道紅線；對白本文加「」。

實作上有個坑：直排下必須用邏輯屬性。`margin-bottom` 在 `vertical-rl` 裡跑的是物理下緣而不是欄距，要用 `margin-block-end` 才會落在正確的軸上。
