# 《新神鵰俠侶》核心設計 V3

**這份取代先前所有設計文件。** V2 那套「不改變事件、沒有數值、關於等待」的命題已作廢，其下的三大機制（語氣選擇、介面剝奪、十六個空白）與六幕劇本一併作廢。

留下來的只有引擎：ink 執行、存讀檔、響應式版面、部署管線。那一層跟故事講什麼無關。

## 一、這款遊戲是什麼

> **把《神鵰俠侶》這個故事，好好講一遍。**

不是解構它，不是拿它當機制實驗的載體。是讓玩家跟著楊過從嘉興的破窯走到華山之巔，把這一路上的人、事、情，一件一件經歷過去。

### 定位參考：昱泉版做了什麼、沒做什麼

昱泉國際 2001 年的《新神鵰俠侶》是 3D RPG，劇情從幼年楊過到斷臂與小龍女跳崖為止。

當年的評價很一致：**戰鬥系統做得好，故事做得差。** 具體被點名的是「劇情演出平庸、迷宮冗長乏味、城鎮缺乏特色，無法展現原著深度」。

**這一版要補的就是它沒做的那一半。** 我們不跟它比 3D 建模與裝備展示，我們比它當年沒有做的東西——把故事講到位。

同時有兩件事值得直接學：

| 昱泉版的做法 | 為什麼值得學 |
|---|---|
| **感情值系統**——影響金錢、召喚動物、與女角的「感情合技」 | 數值是**看得見**的，玩家能算、能追求。不是藏起來的暗數值 |
| **真氣條取代時間條**，不同行動消耗不等量真氣 | 用資源管理取代反射神經，適合敘事節奏 |

## 二、寫作規範（最重要的一節）

前一版失敗的主因是文字口吻。這一節是硬規範。

### 要的

- **第三人稱、過去式、小說筆法。** 段落可以長，句子可以有從句。
- **有畫面、有觸感、有氣味。** 寫他睡的土地廟，泥菩薩缺了一隻手，他每回進門都拍拍那個斷口說一聲「回來了」。
- **對白要有性格。** 楊過嘴上不饒人，郭靖笨拙誠懇，黃蓉話裡有話，小龍女不懂人情。每個人講話都該認得出是誰。
- **可以好笑。** 這個故事有大量的機鋒與少年氣。不准把它寫成一場葬禮。
- **溫度。** 玩家要喜歡這些人，才會在意他們後來怎麼了。

### 不要的

- ❌ 冷短句堆疊（「石壁上有一道縫。縫後面有風。」）
- ❌ 刻意的留白與省略
- ❌ 解構式旁白（「後來他想起⋯⋯」這種把讀者推遠的距離感）
- ❌ 把角色寫成沒有表情的敘述機器
- ❌ 在文本裡解釋機制或設計意圖

### 一條版權底線

**照原著的情節與人物寫，用自己的文字。** 不抄原文、不做近似改寫。招式名稱、地名、人名是事實可以直接用；敘述與對白必須是自己寫的。

### 第十三章要特別處理

前一版把十六年做成「刻意的無聊」，那是錯的。這一次的原則相反：

**十六年要好看。** 它是神鵰俠行走江湖的十六年——他救人、他成傳說、他跟神鵰相依、他每年回斷腸崖描一次字。這些都是有戲的。

做法是**單元劇**：六到八個獨立的短故事，每個都完整，串起來讓玩家看見一個人怎麼從楊過變成神鵰俠。不是六到八個空白。

## 四、兩個看得見的數值

**都顯示給玩家。** 前一版把所有數值藏起來，那是反過來的。

### 情意

與小龍女之間的羈絆。玩家看得見，能追求。

- **增加**：陪伴、信任、為她做的選擇、危急時的維護
- **減少**：欺瞞、為別的事推開她、在關鍵時刻選擇「大局」
- **影響**：
  - 合技「玉女素心劍法」的可用與威力
  - 部分劇情分支與對白
  - 第十二章之後，**黯然銷魂掌的威力**
  - 結局變體

### 俠名

江湖怎麼看他。這個故事的一半就是他在跟自己的名聲搏鬥。

- **增加**：救人、行俠、大勝關這種公開場合的勝利
- **減少**：認歐陽鋒為父、當眾說要娶師父、用蛤蟆功這種被視為邪門的武功
- **影響**：
  - NPC 的態度與可用選項
  - 商店價格、能否借到東西、有沒有人肯幫忙
  - 第十三章傳說內容的形狀
  - 郭襄在第十四章聽到的是什麼樣的神鵰俠

**兩個數值會互相拉扯。** 當眾宣告要娶小龍女——情意大漲，俠名重挫。這一刀是原著的核心，數值要照實反映。

## 五、戰鬥：簡化，但真實存在

敘事為主，所以戰鬥不能拖。但它必須是真的——有招式、有輸贏、有後果。

### 真氣制

借鑑昱泉版：**用真氣取代時間條。**

- 每場戰鬥有一條真氣。招式消耗不等量真氣，普攻回復少量。
- 沒有「等冷卻」，只有「這一招值不值得」。
- 真氣耗盡會強制普攻，形同破綻。

### 一回合做三件事

```
選招式 → 看對手的應對 → 決定追擊或收手
```

- 每個對手有自己的節奏與破綻，看得出來就打得贏。
- 回合上限五回。超過五回，玩家就從讀故事切換成算數學。

### 武功譜（全部出自原著）

| 武功 | 取得 | 特性 |
|---|---|---|
| 全真劍法 | 第三章 | 工整但殘缺，趙志敬留了一手 |
| 蛤蟆功 | 第一章（認歐陽鋒） | 威力大，但用了掉俠名 |
| 玉女心經 | 第四章 | 單人使用威力減半 |
| **玉女素心劍法** | 第四章＋情意門檻 | **合技。兩人同場才能發動** |
| 打狗棒法（殘） | 第六章 | 靈巧，只學到七成 |
| 玄鐵重劍 | 第十章 | 重、慢、真氣消耗大，但一擊定勝負 |
| **黯然銷魂掌** | 第十三章 | **威力隨情意成長。他越想她，這一路越強** |

### 黯然銷魂掌的機制要照原著

原著設定：這路武功是他在十六年的思念裡創出來的，情緒越是低落威力越大。

**所以是情意越高越強，不是越低越強。** 前一版把它做成反向閘門（越相信她回來就越弱），那是為了機制而扭曲原著，這一版改回來。

### 輸了不是 Game Over

劇本寫他該輸的地方就是輸。輸了走的是另一條敘事分支，不是回讀檔點。玩家不必重打。

## 六、美術：光與天空

### 畫風

日系動畫電影的畫面質感，走「光與天空」那一路：

- 背景極度細緻寫實，精細到接近照片，但仍是繪畫
- **天空與雲是畫面的主角**。層次豐富的積雲、透光的雲隙、明確的大氣透視
- 光有體積感：丁達爾光束、逆光輪廓光、鏡頭光斑、空氣中的微塵
- 色彩高飽和但自然：深邃青藍對溫暖橙金。陰影是藍紫色的，不是灰的
- 淺景深與散景，前景常有失焦的枝葉
- 人物用乾淨的動畫線條與通透上色，臉部簡潔，與超細緻的背景形成對比

**禁止**：黑白、低彩度、漫畫網點、墨線排線、厚塗油畫、水墨。

### 用時間與天氣取代分幕色票

前一版用「素白／玄黑／情緋」三色規範分幕，那套隨命題一起作廢。

這個畫風的情緒載體是**光**，所以改用**時辰與天氣**：

| 章 | 時辰／天氣 |
|---|---|
| 一 破窯 | 黃昏，暖金逆光 |
| 二 桃花島 | 晴朗的春日正午 |
| 三 終南山 | 陰天，霧 |
| 四 古墓 | 通風縫落下的一束天光，其餘藍紫陰影 |
| 五 出墓 | 雨後初晴 |
| 八 絕情谷 | 晨霧，情花在霧中發亮 |
| 九 斷臂 | 陰天，無方向的平光。**全作唯一沒有光的一章** |
| 十 海潮 | 暴雨與烏雲 |
| 十二 斷腸崖 | 日落。全作最美的一章 |
| 十三 十六年 | 六到八種不同天氣，每個單元一種 |
| 十六 華山 | 黎明 |

第九章刻意抽掉光。前面八章都有天空，那一章沒有——這比講任何一句話都有效。
